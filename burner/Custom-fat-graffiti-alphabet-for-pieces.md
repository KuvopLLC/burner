## Problem statement

Piece letterforms derive from the 5x7 UI font scaled up and dilated. Real pieces use fat, custom letterforms with bends, overlaps, and arrows built into the letters (see blackbookgraffiti, Subway Art).

## Possible solution

Hand-author a dedicated chunky graffiti alphabet (e.g. 8x10 cells with slants/serifs), used only by makePiece. Keep region/fade pipeline unchanged.
